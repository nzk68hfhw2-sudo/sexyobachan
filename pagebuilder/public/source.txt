個人ページ — 個人ページビルダー / source.txt
(Gravity のゲーム機能で公開する、ブログ・日記・プロフィールの個人ページを作って見せ合う Web アプリ)

======================================================================
0. ファイル構成
======================================================================
[公開されるファイル]  (リポジトリの pagebuilder/public/)
index.html   … Netlify のURLを直接開いたとき用。game.js を読むだけ。
game.js      … 画面の本体(すべてのコード)。DOM・CSS・ロゴの絵を自分で作る。
_headers     … 別のサイト(Gravity)から読み込めるようにする CORS 設定。
source.txt   … この説明。

[サーバー側]  (公開フォルダの外。Netlify が自動で動かす)
pagebuilder/netlify/functions/api.mjs … /api への通信を受ける Netlify Function。
pagebuilder/lib/app.mjs               … サーバーの本体(登録・ログイン・記事・通報・管理)。
保存先                                 … Netlify Blobs の「kojin-pages」という入れ物。

[そのほか]
netlify.toml (リポジトリのいちばん上)  … 「pagebuilder フォルダを公開する」という設定。
pagebuilder/tests/                     … テスト(npm test で実行)。
pagebuilder/deliver/loader_prompt.txt  … Gravity の AI にわたすローダー。

素材: 画像・音のファイルは1つも使っていません。絵文字と、プログラムで描いた絵・模様だけです。
外部ライブラリ: 画面側は 0 個。サーバー側は @netlify/blobs と bcryptjs の2つ。

======================================================================
1. 起動のしくみ
======================================================================
Gravity 側の短いローダーが <script src="https://(サイト)/game.js"> を1本読み込みます。
game.js は自分が読み込まれたURLからサイトの場所を知り、同じサイトの /api と通信します。
iframe も fetch による本体の読み込みも使いません。
画面は Shadow DOM の中に作るので、Gravity 側のページの見た目とまざりません。

サーバーとの通信は、まず fetch(POST)を試し、禁止されている場所では自動で
script タグ方式(JSONP)に切りかえます。長い本文は小分けにして送ります。

======================================================================
2. ログインのしくみ(Cookie を使わない)
======================================================================
ログインに成功すると、サーバーが長いランダムな「合い言葉(トークン)」を返します。
game.js はそれをおぼえておき、通信のたびにいっしょに送ります。Cookie は使いません。
ブラウザの保存が消えたら、ID とパスワードで入り直せば元どおりです(データはサーバーにあります)。
・パスワードは bcrypt でハッシュ化して保存(平文は保存しない)。8文字以上。
・合い言葉もサーバーにはハッシュだけ保存。期限は30日。
・同じ ID に5回まちがえると15分ロック。
・管理者の ID は、Netlify に設定した合言葉(ADMIN_SETUP_CODE)がないと登録できない。

======================================================================
3. 安全のための決まり
======================================================================
・ほかの人が書いた文章は、すべて「文字」として表示(textContent)。HTML として解釈しない。
・使える記法は **太字** / # 見出し / ## 小見出し / - 箇条書き / > 引用 / --- 区切り線 だけ。
  リンクも画像も作れない。
・色は #rrggbb の形だけ、テーマ・フォント・飾りは決まった一覧からだけ、アイコンは絵文字だけ。
  サーバーと画面の両方で確かめる。
・上限: 本文4000字 / 題名60字 / 自己紹介300字 / コメント100字 / タグ5個(各15字)
        記事と日記は合わせて1人100件 / 新しい投稿は20秒に1回 / コメントは10秒に1回
・画像のアップロード機能は無い。
・各ページとコメントに通報ボタン。管理者は管理画面で確認・非表示・削除・アカウント削除ができる。
・書く画面に「本名、住所、学校名、連絡先は書かないでください」を表示。

======================================================================
4. 公開範囲
======================================================================
全体に公開          … 新着と検索に出る。
URLを知っている人だけ … 新着と検索に出ない。URL(またはコード)を知っている人だけ読める。
自分だけ            … 本人だけ。
記事はこれとは別に「下書き/公開」があり、下書きは本人にしか見えない。

======================================================================
5. 保存データのキー (Netlify Blobs)
======================================================================
user/<id>            ログイン情報(パスワードのハッシュ)
sess/<id>/<hash>     ログイン中の合い言葉(ハッシュ)
page/<id>            プロフィールとデザイン
post/<id>/<記事ID>   記事・日記の本体        pidx/<id>  その人の記事一覧
idx/posts, idx/users 新着と検索のための一覧
stat/<id>/<対象>     いいね・足あと・コメントの数
like/<id>/...        その人が押したいいね
cmt/<id>/<対象>      コメント               mycmt/<id>/...  その人が書いたコメントの場所
report/...           通報                   rl/...  回数制限のカウンター

======================================================================
6. Gravity に投稿する  (v1.3)
======================================================================
Gravity の投稿には URL が貼れないので、自分の日記・記事・ページを次の方法で投稿できる。
(1) そのページだけを表示する「ゲーム」として投稿する
    「Gravityに投稿する」ボタンが、そのページ専用のローダー(Gravity の AI に送る文章)を作る。
    ローダーは game.js?view=コード を読み込む。game.js は view がついていると「表示専用モード」
    になり、ページを作る画面(上の帯・下のタブ)を出さず、その日記やページだけを表示する。
    下には「ログイン / 自分のページを作る」の入口だけを出す。
    内容は毎回サーバーから読むので、編集すれば Gravity 側も新しくなり、
    削除や非公開にすれば表示されなくなる。
(2) 文章だけで投稿する
    URL をふくまない投稿用の文章を作ってコピーできる。
※ Gravity のプロフィール画像の自動読み取りは、Gravity がゲームに情報をわたしていないため
   できないと分かったので、機能ごと外した。カード画像の機能も外した。
