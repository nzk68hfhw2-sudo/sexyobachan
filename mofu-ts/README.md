# モフ山のTypeScript

モフ山を舞台に、TypeScript を少しずつ学ぶブラウザ学習ゲームです。
型は「モフたちが入る専用の箱」というたとえで説明します。

- 時間制限、点数、ランキングはありません
- 1ステージ 5〜10分。問題を1問解くたびに自動で保存されます
- ヒントは3段階。好きなときに、自分で開けます
- 「今日は1問だけ」モードがあります
- いま遊べるのはステージ1〜3です

## 遊び方（はじめての準備）

Node.js（18以上）が入っているパソコンで、このフォルダ（`mofu-ts/`）に移動して実行します。

```sh
npm install      # 最初の1回だけ
npm run dev      # ゲームを起動
```

表示された `http://localhost:5173/` をブラウザで開くと遊べます。
終わるときは、ターミナルで `Ctrl + C` を押します。

## 開発用のコマンド

| コマンド | すること |
| --- | --- |
| `npm run dev` | 開発用に起動（書きかえるとすぐ反映） |
| `npm run check` | ゲーム本体の型チェック |
| `npm run verify` | すべての問題が、ねらい通りに判定されるか確かめる |
| `npm run build` | 公開用のファイルを `dist/` に作る |
| `npm run preview` | `dist/` の中身をブラウザで確かめる |

## ソースの読み方

ゲーム自体も TypeScript で書かれていて、コメントは日本語です。ステージを進めたあとに読むと、習った書き方がたくさん出てきます。

- `src/types.ts`：ゲーム全体で使う型。最初に読むならここ
- `src/game.ts`：画面の流れを決める司令塔
- `src/engine/compiler.ts`：ブラウザの中で TypeScript コンパイラ（見張り番）を動かす
- `src/engine/errorDict.ts`：エラーをやさしい日本語にする辞書
- `src/stages/stage1.ts`〜：問題のデータ
- `src/state/save.ts`：保存と、文字列でのコピー・復元
- `src/ui/`：画面の部品
