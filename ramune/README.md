# キケンなラムネシミュレーター

架空の「ラムネ」とチューハイ「ZER9」で夜8時〜朝8時をすごす、ブラウザ用フル3Dシミュレーター。
家の中は自由に歩けます：リビング（キッチン）・ベランダ・トイレ・廊下・玄関・和室（こたつ・ふとん）・お風呂（湯船・シャワー）。
**フィクションです。登場するラムネ・お酒・効果・飲み合わせはすべて架空で、実在の薬物・製品とは関係ありません。**

- 体のシミュレーション：効きはじめ・ピーク・切れぎわ（反動）、耐性、心拍・体温・呼吸・意識・水分、吐き気と嘔吐、気絶、危険度
- 3D表現：壁が呼吸する・天井が溶けて星空になる・万華鏡・残像・幾何学の浮遊物（幻覚）／二重視・ふらつき（お酒）／体外離脱で自分の背中が見える（解離）／影の人・壁を歩く虫・ソファに座る“だれか”（とばり）／ハートと光の粒（ハート）／まぶたが落ちる（鎮静）

- 救済手段：水、ベランダの夜風、トイレで吐く、リセットラムネ、📱119番（救急搬送エンド）
- エンディング：GOOD MORNING／気づいたら朝／救急搬送／BAD END（原因別に現実の注意も表示）
- スマホ：📞電話（架空の友達4人。状態で会話が変わり、危ないときは救急車を呼んでくれる）／💬メッセージ（酔うと誤字だらけ、友達から返信や連絡も来る）／🌙ナイトライン（架空SNS。見えている景色を撮って投稿、いいね・返信がつく。酔って投稿したものは朝のリザルトに出る）
- トイレ：便器に吐く・流す・座って休む（かがみこむ演出つき）。トイレ以外で吐くと床が汚れ、ふいて掃除できる
- 図鑑（ラムネ・飲み合わせ）は端末に保存。光の点滅をおさえるモードあり。

## 操作
- スマホ：左側ドラッグ＝移動、右側ドラッグ＝見回す、モノをタップ＝しらべる、▶1x ボタンで時間の速さ 1→2→4→8 倍、📱スマホ
- PC：WASD 移動、マウスドラッグで見回す、クリック/E しらべる、F 時間の速さ切りかえ、Tab スマホ、R ラムネ、Q 冷蔵庫

## ファイル
- 名前：どのラムネにも医薬品風の名前（例：ルミセルジン）とストリート風の通称（例：ゆめいろラムネ）、錠剤の刻印がありますが、**すべて架空**です。系統ごとに「現実では…」の注意を表示します。
- `src/*.js` … ソース（`node tools/build.js` で `dist/game.js` に結合）
- `dist/game.js` … 本体（DOM・UI・3D・音をすべて自分で作る。three.js r128 は cdnjs から読む）
- `dist/index.html` … game.js を読むだけのページ
- `dist/ramune_night_standalone.html` … game.js を埋め込んだ 1 ファイル版
- `deliver/loader_prompt.txt` … Gravity に貼るプロンプト（小さなローダーHTML）
- `tools/simtest.js` … 体のシミュレーションのバランス確認（`node tools/simtest.js [v] [名前]`）

## Gravity への公開
`deliver/loader_prompt.txt` の中身をそのまま Gravity のゲーム作成に貼ってください。
ローダーは GitHub のこのリポジトリ（公開）の `ramune/dist/game.js` を、コミット固定の URL で
jsDelivr → fastly.jsdelivr → statically → githack の順に読みにいきます（どれか1つ届けばOK）。
Netlify などに `dist/` を置いた場合は、`node tools/make_loader.js <コミットSHA> https://あなたのサイト/game.js` でそのURLも候補に足せます。
